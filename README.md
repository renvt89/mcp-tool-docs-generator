# MCP Tool Docs Generator

- **What it is:** MCP Tool Docs Generator, a package that turns an MCP (Model Context Protocol) server's tool definitions into readable documentation that covers tool names, descriptions and input schemas.
- **Who it is for:** developers who publish or maintain MCP servers and need clear tool docs for users and MCP directories.
- **How it is delivered:** a ZIP download from Gumroad. The package is published and supported by Rene Vergara.
- **Price:** shown on the Gumroad page.
- **Get it:** https://renevibe76.gumroad.com/l/bmzwpm

## About this repository

This is the public listing repository for MCP Tool Docs Generator, used by MCP directories. The full package (source, usage notes and examples) is the Gumroad download linked above.
